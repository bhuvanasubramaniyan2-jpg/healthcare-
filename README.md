# Healthcare Chatbot

A simple Flask-based Healthcare Information Chatbot.

## Structure

app.py
config.py
requirements.txt
.env
.gitignore
README.md
templates/index.html
static/style.css
static/script.js

## Local run

pip install -r requirements.txt
python app.py

Open http://127.0.0.1:5000

## Gunicorn

gunicorn app:app

This chatbot provides general educational information and is not a substitute for professional medical advice.
